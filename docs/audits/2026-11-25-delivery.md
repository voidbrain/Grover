## Results

- **CI**: 79 CI runs since the rebuild; 75 passed. The latest main run (45603921768, `c908fa6`) passed every step; the one skipped step, "Built backlog views", is skipped by configuration (built views not adopted, #36). Of the four failures: one main run (45462780952) failed in the e2e probe-read test, a race fixed in the test by #19 and recorded in F-012; three PR runs failed in the feed e2e test, and one of them (45487054804 on `a790c83`) passed on the next commit, which changed only docs: an intermittent failure (finding 1).
- **Workflow pinning and versions**: actions are pinned by full SHA; CI uses Node 24 as `.nvmrc` and `engines` say; `packageManager` pins npm 11.17.0; `npm ci` from the committed lockfile. The maintenance workflow runs on Node 22: its tools are plain `.mjs` and the dispatched run passed, so this is noted only.
- **Scheduled maintenance workflow**: registered 2026-11-24 18:18 UTC with a daily 09:00 UTC cron, but no scheduled run exists yet; the manual dispatch today passed (finding 3).
- **Harness template check**: `.harness.json` names no template repository, so CI's template release check is skipped by design; session-start freshness covers it locally.
- **Branch protection**: `main` has none (API 404). Merges go through `tools/merge-when-green.mjs`, which waits for every check, so the rule "never merge with a failing check" rests on the agent's procedure, not on GitHub. Changing it is a repository setting (ask-first); recorded as a proposal (finding 4).
- **Dependencies and supply chain**: 0 `npm audit` findings; all 41 Dependabot alerts are fixed; Dependabot security updates are enabled. CI generates a CycloneDX SBOM per run. Eight Dependabot PRs from 2021–2023 against the removed v1 tree remain open and the last Dependabot security job failed on the removed directory (finding 2).
- **Release and deploy**: no release, tag after `legacy-v1`, or GitHub Pages site; the old "Deploy Angular to GitHub Pages" workflow no longer exists. Nothing is deployed: the Pi install is F-005-T01 (owner, Ready), hardware bring-up F-003. `deploy/` units and the README steps were read, not run (finding 5). A merge is not a release: every feature on `main` is verified on the dev stack or by tests only.
